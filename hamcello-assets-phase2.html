HAMCELLO QUESTPHASE 02 / ASSET STUDY / 01 YOKOHAMA

横浜の景色を、
動かせる素材に。

港から観覧車、赤レンガへ。背景の原画と動くものを別々に制作した。見た目を確認しながら、次の工程で「ジャンプする・乗る・進む」を実装する。

第2工程　素材制作 v1
YOKOHAMA / 背景原画
空を大きく取り、港・観覧車・赤レンガが同じ遠景に収まるようにした。これは背景の雰囲気を確認する原画で、最終的な連続マップへの配置は次工程で調整する。

01　動かせるオブジェクト

FERRIS WHEEL / HARBOR / RED BRICK

観覧車

回転部と支柱を別素材にした。ゴンドラへの乗車時は回転角を使ってハムチェの位置を計算する。

港のクレーンとコンテナ

クレーンは巻き上げ動作を、コンテナはジャンプの障害物・足場として使用する。

赤レンガ倉庫

倉庫の外観を独立素材にした。扉の開閉と木箱が出てくる演出は次工程で組み立てる。

02　ハムチェの動作フレーム

ORIGINAL CUTOUT / MOTION TEST
ハムチェは、ハムチェのまま。

もとの切り抜き写真を使用。姿勢を少しずつ回転・縮小した6種類の仮フレームを用意した。顔つきが変わらないか先に確認するための素材で、別々に撮った本物のポーズ写真ではない。

選択中：立つ（元の切り抜き）

03　マップに組み込むときのルール

3-LAYER SCENERY / CONSISTENT SCALE
LAYER 01 / 0.25×遠景

空、港の景色、遠くのみなとみらい。ハムチェよりゆっくり動く。生成した背景原画を出発点にする。

LAYER 02 / 0.65×中景

観覧車・倉庫・クレーン。近づくほど大きく見せ、実際に動くパーツは独立SVGで管理する。

LAYER 03 / 1×前景

芝生、土の断面、木箱、足場とハムチェ。地面は切らずに続け、ジャンプは障害物の座標に合わせる。

次は、横浜を「実際に進める」状態へ。

港から観覧車、赤レンガまでを一つの連続マップに組み込み、木箱の着地位置、観覧車への乗車・上昇・下車を動作確認する。今回の素材を使い、白画面や固まりの出ない実装を検証する。
